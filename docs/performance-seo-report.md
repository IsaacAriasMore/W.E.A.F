## Architecture Applied

- **Auth deferred:** `startApp()` is no longer `async`. Auth (`authService`, `profileService`) loads via dynamic `import()` after first paint. The router blocks on `waitForAuth()` only when a protected route is requested.
- **CSS split:** The global import of `auth.css`, `app.css`, `breeds.css`, `admin.css`, `servers.css`, `marketplace.css` was removed from `src/main.js`. Each route imports its own CSS via a hoisted `import` at the bottom of the route module.
- **Fonts self-hosted:** `@fontsource-variable/archivo` replaced with local `@font-face` blocks using `font-display: optional`, unicode-range segmentation, and three woff2 files (~79 KB total). Fallback: `system-ui, sans-serif`.
- **Loading shell:** `.route-loading` height changed from `65dvh` to `calc(100svh - 70px)` with a `65dvh` fallback. Matching `padding-block` reduction.
- **Service Worker:** Cache bumped to `weaf-shell-v6`. Private routes are excluded from cache.

## Image Optimisation

- Brand emblem converted to AVIF + WebP `<picture>` with four widths (44, 88, 112, 224).
- `BrandEmblem.js` component generates the `<picture>` element with `srcset` and `sizes`.
- OG image created as `weaf-og-1200x630.webp` (33 KB).

## Public Render and Deferred Auth

- Public content renders immediately without waiting for Supabase session recovery.
- Auth modules are lazy‑loaded only when the user visits a route that needs authentication.
- The router shows a skeleton (`aria-label="Validando sesión"`) while auth initialises, then redirects or renders the protected page.

## Deferred Three.js and GSAP

- `WeafThreeHero` now schedules via `requestIdleCallback` (timeout 2600 ms) or `setTimeout` (900 ms), and only after `document.readyState === 'complete'`.
- GSAP hero fade‑in animation (`data-gsap-hero`) was removed. Only stagger (`data-gsap-stagger`) with `IntersectionObserver` remains.
- `SponsoredServerSlot` lazily imports `createServerService` and hydrates via `IntersectionObserver` (500 px rootMargin) or `requestIdleCallback`.
